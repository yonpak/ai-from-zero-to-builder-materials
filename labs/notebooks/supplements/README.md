# Optional P5 and P7 PyTorch notebooks

These are unnumbered, optional notebooks for the P5 and P7 guides. The `.external.json` files describe the "Open notebook in Google Colab" launcher on the website; they are not regular course Lab manifests, and these notebooks do not count toward course progress.

Use the **Open notebook in Google Colab** launcher on the P5/P7 page. After public materials publication it opens in one click. Until then, download the `.ipynb` from the website `/labs/notebooks/supplements/` and choose Colab File → Upload notebook. Connect (CPU), Runtime → Run all. Both are self-contained and need only torch (PyTorch 2.x). No project credentials, external datasets or GPUs are needed.

Smoke check from the repository root (once torch is installed):
`python labs/notebooks/supplements/smoke_test.py`.

Run cells in order. Change only the variable described in the first markdown cell and rerun from the top. The P5 writing appendix is intentionally deferred until just before project p03.
