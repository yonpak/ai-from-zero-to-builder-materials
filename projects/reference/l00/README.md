# p00 reference evaluation assets

`reference_solution.py` is a sample implementation used to verify the project contract and demonstrate rubric application. It is intentionally separate from the learner starter.

From the repository root, verify it with:

```bash
python projects/tests/l00/test_reference.py
```

Expected output:

```text
PASS: p00 reference solution satisfies objective validator
```

See `sample_evaluation.md` for an example of applying the rubric without requiring byte-identical learner output.
