# p04 Tokenizer Workbench reference package

This directory contains the published reference implementation and a sample rubric application. Try the starter TODOs before comparing the code for `p04-tokenizer-workbench`.

Run from the repository root:

```bash
python projects/tests/l04/test_reference.py
python projects/tests/l04/validate_submission.py projects/reference/l04/reference_solution.py
```

Expected evidence:

```text
PASS: p04 reference solution satisfies objective validator
PASS: p04-tokenizer-workbench objective checks
```

The reference solution is deterministic, standard-library-only, and uses the same committed synthetic text fixtures as the learner starter. It is an evaluation example, not a byte-identical output requirement for learners.
